## Mathematical outcome

The fixed-rate source's saved path labels can be publicly unshuffled with
the live point into original root coordinates and constant auxiliary tags.
The resulting polynomial number of transverse rows preserves physical
sharing and gives fixed-tag translated-seed queries. An explicit shared
label table is therefore feasible in this model.

The more useful limitation is that direct shared row polynomials subsume
guessed tag layouts at the same clause degree and time cost. At a fixed
used-cell error budget, public dense global degree differs from the best
adaptive tag degree by at most the logarithm of the row count. Full-row
coverage extends the limitation to consistent recodings whose actual query
values stay low degree. The conditional hierarchy consequence preserves the
minimum over all satisfying witnesses.
