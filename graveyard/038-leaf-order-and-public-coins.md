# Two failed shortcuts in compiling the recursive read

**Treat the same collection of leaf addresses as the same ordered answer vector.** Offsets enumerate all the desired points and preserve the root bits. They permute the answers by a seed-dependent translation. On the table (0,1), an ordered predicate selecting the first answer changes value when the inherited leaf coordinate is 1. In the actual coefficient encoding, a one-edge row path at (k,a)=(7,3), root seed 1 and zero fresh pads sends slot zero to address 0 in the absolute convention and 4 in the relative convention. A proof assigning different bits to those cells distinguishes these ordered reads. Reindex with public data, or prove translation invariance for the particular complete predicate. The leaf RS membership property has such an invariance. Arbitrary signed clauses need more information. [Replay and check](../expeditions/038-recursive-query-fibers/attacks.md)

**Put public randomness in unverified proof cells.** This makes answer-only clauses easy to write, but a dishonest global proof can invent a different seed at every gate table entry. In the public test “the two seed bits are different”, two of four seeds should reject. With freely chosen copies of the seed and gate witnesses all circuit clauses can pass. For each public bit b, pin its value to ε on the whole subcube z_b=ε using the address obtained by clamping b. Across all 4,096 possible wire tables, adding the pins restores at least two rejected seed/test pairs out of 36. The source verifier is not implicated in either failed implementation.
