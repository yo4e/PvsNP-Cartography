# Implementing the printed row marker with the displayed row origin

**Failed rule.** In the 9 February 2014 report *Short PCPs with projection queries*, §6.3 gives a bit test for redirecting a row query to its parent. Combining that bit test literally with the row parametrization printed in the same paragraph sends the wrong points to the parent. This note concerns that pair of coordinate conventions. [Ben-Sasson and Viola, pp. 17–21, especially Eqs. (6), (7), (9), Definition 6.2 and §6.3](https://eccc.weizmann.ac.il/report/2014/017/download/)

**Coordinates.** Fix a row labelled by β. Write the displayed point as α = β + u + v + t(c₀ + β), with u in L₀, v in the span of the auxiliary basis c₁,…,cₐ₋₁ and t a bit. Eq. (9) gives the parent's points in this row as precisely α in β + L₀. Independence of the displayed row basis makes the coefficients unique. Membership is therefore equivalent to v=0 and t=0. The row paragraph instead prints v=0 and t=1.

**Two decisive evaluations.** With u=v=0, t=0 gives α=β, a parent point. With the same u,v, t=1 gives α=c₀, outside the parent coset because c₀+β is independent of L₀. Both directions of the literal test fail. More generally, all queried column labels lie in c₀+L₀+span(c₁,…,cₐ₋₁), on the t=1 side of the displayed coordinates. Proposition 6.1 says these columns are disjoint from the parent set T.

**Repair and check.** Use the geometric membership rule with the displayed origin β. Alternatively, change the origin to c₀ and complement the recorded bit: the same points now have the opposite bit values. Flipping only the test while retaining an origin that already uses complemented coordinates would reintroduce the error. The executable control [verify_rs_level.py](../expeditions/037-source-query-audit/verify_rs_level.py) checks point membership against an explicitly enumerated parent set. It represents addition of independent basis vectors by XOR; the local comparison needs no field multiplication.

**What survives at one level.** Write the parent's seed as low bits L and high bits H. A row has edge label H. On its parent subspace the row coordinate contributes L, and the marker coefficients are fixed. The parent coordinate recovers both L and H. A column's local coordinate gives the row index H and its edge label gives the column point, retained in the redirected row location. Dropping labels would destroy this accounting. A fixed occurrence at a leaf can overwrite the remaining local seed (leaf dimension at most 2a); one must also account for pre-fixed control bits, full-address layout and all upper levels before bounding a complete query fiber.

The underlying geometric construction supplies the repair. This is a counterexample to a literal implementation of the printed rule, with novelty unknown. It supplies no counterexample to the source PCP theorem.
