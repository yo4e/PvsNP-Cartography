# A local read lower bound for certifying an entire outer row

The two- and three-level repairs first infer a degree bound on the *entire* selected outer row from one bundled public-seed success. At fixed rate exponent $a$, this particular implication has a query cost which is exponential in the root dimension $k$.

Fix a public seed, its outer row label $v$, and one global all-zero proof. Take a verifier which accepts that proof at this seed. Suppose this one acceptance is intended to imply, for arbitrary assignments to the physically shared cells, that the whole selected row is an RS codeword. Let $l=\lfloor k/2\rfloor$. The row has $2^{l+a}$ distinct physical symbols on different abscissae, with degree strictly below $2^l$. Its parent and column aliases are other names for the same cells. Count reads at their physical addresses after following every redirect, including reads from any extra translated calls.

If even one of the row's physical symbols is unread, change only that symbol from zero to one. The external root alphabet and the extension alphabet both allow this change. All queried symbols stay unchanged, so acceptance at this seed persists. The changed row has $2^{l+a}-1$ zero values. A degree-$<2^l$ polynomial vanishing there is identically zero and cannot give the changed value. This contradicts the proposed implication. Therefore each such accepting test must read all $2^{l+a}$ symbols of its chosen row on the zero proof. The argument still works for an adaptive decision rule by keeping its zero-proof transcript fixed.

For the shared RS tree, one bundled call at one seed enumerates at most $B=2^a+2^{a-1}$ distinct row/column fresh choices per internal node. Each leaf reads at most $2^{2a}$ symbols. The depth bound from [the source compiler](../038-recursive-query-fibers/source-compiler.md) is $h=1+\lfloor\log_2(k-2a)\rfloor$ for $k>2a$. Thus $L(k,a)=2^{2a}B^h$ upper-bounds all raw symbol occurrences of one bundled call. This overcounts repeated leaves and aliases, which is safe for the read lower bound. Any collection of $t$ original calls which certifies a whole outer row in this sense must satisfy $tL(k,a)\ge 2^{l+a}$. For fixed $a$ the denominator $L(k,a)$ is polynomial in $k$. A polynomial number of translated calls cannot certify an entire outer row on every accepting seed at unbounded $k$.

This obstruction is specific to that intermediate conclusion, irrespective of how the translations are selected. A single modified symbol can leave a root at vanishingly small distance or even leave it unchanged when the symbol is an auxiliary. The argument gives no counterexample to a rejection bound averaged over the public seed, or to existence of a polynomial agreeing on the accepted **root** sites. A deeper proof can instead charge inconsistent regions across many seeds or decode just those root sites. That distinction matters for the source compiler's polynomial query budget.
