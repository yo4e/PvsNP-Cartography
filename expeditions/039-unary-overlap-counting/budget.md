# The width, error and nondeterministic time ledger

## One hard unary language

Take t₂(n)=2^n and, above a fixed small length, the constructible dyadic clock t₁(n)=2^{n−ceil(log₂(n+2))}. Then t₁(n+1)/t₂(n) tends to zero. Fix one unary L in NTIME(t₂) outside NTIME(t₁) by the unary nondeterministic hierarchy. This fixes the language *before* choosing any approximation and any small degree coefficient. The BV14 application also uses a unary language. Williams states the unary hierarchy as Theorem 2.1 and discusses the polylogarithmic simulation overhead in Theorem 2.2. The time ledger below reserves any fixed extra polynomial in n for those model conversions; arithmetic on exponentially long words is not a unit-cost operation.

For the published verifier, k≤n+O(log(n+2)) is the randomness/proof-address width and J=poly(n) the number of literal occurrences. Pad the seed by unused bits to at least n if necessary, leaving the distribution on genuine bits unchanged. Pick a fixed integer C so that W(n)=n+C ceil(log₂(n+2))+C covers k+ceil(log₂ J) for every n. The map is strictly increasing, computable, and has a polynomial-time range test and inverse on its image. At length W(n) the instance is 1^n. Construct the polynomially many signed projection templates; explicitly expand their clauses on every genuine seed in 2^{O(n)} time. Use a SAT oracle to test satisfiability, then to fix each physical proof bit lexicographically by testing a prefix extension. There are at most 2^{O(n)} queries of length at most 2^{O(n)}. One can perform the prefix search once per target computation. Compute the target bit by its representation after choosing this same physical proof. This gives one uniform language in E^NP. On NO and unused lengths output zero. The fast nondeterministic hierarchy simulator below never calls that oracle.

W(n+1)−W(n)=C+1 at n=2^j−2, j≥1, so infinitely many lengths are unused. Infinite occurrence of an easy length says nothing about approximations on all large YES instances. If all but finitely many YES instances had an approximant meeting the budget, the simulator would accept those YES instances and reject every NO instance. Finitely many exceptions can be hardwired and nonunary inputs rejected directly. This contradicts the choice of L. Thus the candidate conclusion concerns infinitely many **occupied YES** lengths. No almost-everywhere claim follows.

## Physical bits versus occurrence bits

For the Expedition 038 physical-proof layout, let m₀ be its native bit width. Zero-fill outside one fixed slice at width W. Uniform error η can yield 2^{W−m₀}η on that slice. Alternatively, use the same canonical physical bit on *every* additional padding slice. Then the best uniform error of a degree-d polynomial is exactly the native optimum: each restriction has degree ≤d and their mean is the full error; conversely extend a best native polynomial by ignoring padding. Guess a single native polynomial. The fixed physical queries are evaluated by that polynomial, so no verifier resampling or consistency obligation is introduced. The sufficient condition in 038 improves to 3·2^{m₀−k+1}η < γ/M, still conditional on that compiler's stated bounds. This removes only the **external** padding loss.

The occurrence-bit representation in the [overlap argument](weighted-overlap.md) instead uses the published signed-clause interface directly. It spends J 2^{ceil(log₂ J)} on uniform approximation when the score is a sum over clauses. Its YES and NO thresholds are explicitly separated in that argument. These are different target functions and different guesses.

## Guess, build, count, compare

Set d=floor(α W/log₂ W) for a fixed sufficiently small positive dyadic α (an integer-log rounding gives an equivalent constructible degree budget). For definiteness one can use ceil(log₂ W) in this definition. Let B(k,d)=Σ_{i≤min(d,k)} binom(k,i). A table on r≤k native bits takes B(r,d) coefficients. Guess at most J B(k,d) bits; for the physical-proof version guess one native table of the analogous width m₀. For d=O(n/log n) this is 2^{O(d log(e n/d))+O(log n)}=2^{o(n)}. A signed substitution can expand each monomial to at most 2^d terms. Construct each degree-3d clause by up to three products in the Boolean quotient and sort identical masks to cancel parity. Even a cubic expansion in 2^d B(k,d), with polynomial bit costs, is 2^{o(n)}. Signed overlap constraints and all pairwise image descriptions cost polynomial in n; no truth table of a full proof is guessed in this simulator.

Viola's Theorem 12 counts a degree-D Boolean polynomial on k bits in time 2^{k−c k/D+O(log k)} for some c>0 (degree zero is direct). For overlap terms in fewer variables one may pad to k and divide out the known dummy multiplicity. There are at most M+binom(J,2) calls, each with D≤3d. Write k≤n+u log₂ n and absorb the number of calls, bit costs, and fixed model-conversion losses into n^v. Then the dominant upper bound is 2^{n+(u+v)log₂ n−c k/(3d)}, apart from 2^{o(n)} construction. For large n, k≥n and W/n→1, hence k/d≥log₂(n)/(2α). Choose α with c/(6α)>u+v+3. This pays the full polynomial overhead and fits t₁. No numerical α is exported from a big-O source. The previous root-counter work supplies exact finite checks; this asymptotic time bound invokes the published counting theorem.

**Classification.** On the external PCP, counting, and hierarchy theorems, the occurrence construction gives a *written candidate derivation* of a family in E^NP with inverse-polynomial uniform error lower bound against every GF(2) polynomial of degree floor(αW/ceil(log₂ W)) on infinitely many occupied YES lengths. J≤W^{O(1)}, so 1/(4J 2^{ceil(log₂ J)}) is bounded below by W^{-B} for some fixed B at large lengths. This is a weak error guarantee in a large uniform class. The coefficient α and error exponent are not numerical performance claims. Prior-art comparisons and a separate encoding are recorded in the conclusion. No theorem-state promotion has been made.
