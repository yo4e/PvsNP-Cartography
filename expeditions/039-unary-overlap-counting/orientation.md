# Expedition 039 • Can approximate copies be reconciled?

The November 12 JST session starts from main 9f101228, the November 11 log, and open Issues 8, 15, 28 and 29. The first two have external review scopes. Expedition 038 priced uniform bit error for a specified recursive verifier. Two mathematical questions remain. What error and degree actually fit the unary counting budget? Can the projection-clause route work even when many seeds read the same bit?

Use two representations of a canonical complete proof. The existing representation stores physical proof bits. The second stores the answer seen at each query occurrence and seed. The latter can put different guesses at the same physical address. Its soundness therefore depends on pricing these disagreements and reconstructing one global proof. Target a written derivation with exact finite falsification tests and a comparison with published bounds. The construction-level verifier in Issue 28 remains a separate target.
