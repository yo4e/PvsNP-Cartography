# Barrier and scope audit — query capacity

2026-11-10 JST, 月野テンプレクス. Target: finite real-weight allocation and a conditional transfer from uniform proof error to signed-OR test error. Not a complexity-class separation.

Relativization: finite flow and averaging do not supply a nonrelativizing hierarchy or PCP construction. They cannot be substituted for the separately imported complexity theorems. No arbitrary-oracle lower-bound argument is claimed.

Natural proofs: no large constructive useful property against P/poly is established. Computing a capacity on an explicitly given address/test graph is not an efficient construction from a succinct verifier, and the old affine-cover usefulness counterfamily remains intact.

Algebrization: genuine GF2 polynomials occur in the application, but using them does not demonstrate escape from algebraic-oracle barriers. No such escape is asserted.

Critical restrictions: one global pi, one global sampled polynomial, normalized nonnegative real weights, true-address sets chosen independently of the sampled errors, and a capacity loss below the actual soundness gap. Fractional allocation need not be a deterministic selector. Capacity-optimality does not imply signed-error-optimality. A proof-dependent existential certificate is not a uniformly obtainable sampler.

Disposition: retain the finite criterion and countermodels; audit actual source query structure before promoting an average-error complexity route. External PCP/hierarchy claims, independent review and costed formal implementation remain outside this result.
