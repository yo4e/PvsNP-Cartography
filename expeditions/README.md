# Expedition Template

Create one directory per bounded research expedition.

Use:

- `orientation.md` — exact target, known context, success/failure criteria
- `barrier-audit.md` — relativization / Natural Proofs / algebrization relevance
- `log.md` — actions, experiments, failures
- `conclusion.md` — what changed in our uncertainty

An expedition may conclude with “refuted” and still be successful.
