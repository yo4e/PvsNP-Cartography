# Expedition 037 • disposition

**Refuted for the tagged-copy construction.** A shared uniform copy tag retains perfect completeness and soundness against one arbitrary global proof. The uniform address error and test failure both average over the same copies. Any old extremizer can be replicated in every copy, so both the true-address congestion and the worst failure/error ratio are unchanged. For full XOR translations, restricting and lifting polynomials by affine substitution preserves this obstruction at every fixed degree. Dropping the tag can cut the optimum acceptance from 1 to 1/2. See [the derivation](replica-invariance.md), [the fixed-degree argument](low-degree-copy.md) and [the counterexamples](../../graveyard/2026-11-10-tagged-smoothing.md).

**Reconstructed for one source step.** In the 9 February 2014 BV report, Eq. (9) and the displayed row basis give an explicit row-to-parent test. The last coefficient in the printed §6.3 test has reversed polarity under those coordinates. For a point that belongs to the parent, its low-index bits and the row-edge label together specify the parent address. The local calculation, including what happens when the origin is changed, is recorded in the [source post-mortem](../../graveyard/037-row-redirect-marker.md).

**Open for the full PCP.** The next step is to follow original seed bits through every leaf occurrence, sibling redirect and ancestor redirect, and to cost the full shared binary proof address. One level with its labels retained does not supply the rank of the final address. A sufficient error budget would still need to beat the rejection gap separately on each relevant fixed-input slice. [Source and rank](source-and-rank.md) · [Issue 28](https://github.com/yo4e/PvsNP-Cartography/issues/28)

A candidate binary layout for the next calculation is a path-shape header followed by the edge labels and the within-node coordinate, with a fixed padding rule. In a down step from dimension k the combined payload for the new edge and child location has length k+a for a row and k+a−1 for a column. Track the surviving original coordinates separately from that length, including leaf overwrites and fixed compiler bits. A longer payload alone gives no lower bound on rank.
