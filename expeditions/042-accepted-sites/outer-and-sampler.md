# One residual evaluation after repeating the proximity checks

Write N = 2^k and identify the external field's additive group with the binary seed cube. Fix a single assignment to every physical proof cell. For each external word i, let E_i be the rejecting seeds of its original all-fresh-tapes proximity predicate. Let p_i = |E_i|/N and let δ_i denote distance to the corresponding external Reed–Solomon code. Use the Expedition 038 hypothesis δ_i ≤ C_i p_i, including the alphabet projection and physical aliases. The proof below needs this bound at the actual distance of each word. A guarantee at just one fixed distance threshold would give less.

## A polynomial schedule

For each word i, fix a multiset H_i of masks with all nontrivial weighted character biases bounded by λ_i. Run its proximity check at each x+h for h in the support. Enumerate the check's previous fresh tapes at each call. Evaluate the outer constraint exactly once at x. Choose the mask list from the dimension and precision, independently of the proof, seed and instance values.

An explicit choice takes Q the least power of two at least max(2,(k−1)/λ_i) and fixes binary coordinates on GF(Q). For every y,w in this field, use the k-bit mask whose bit j is the binary dot product of w and y^j, for 0 ≤ j < k and y^0 = 1. The sign of the parity indexed by a nonzero binary vector c has conditional mean zero over w unless the sum of c_j y^j vanishes. The degree bound gives mean at most (k−1)/Q across all Q² parameter pairs with multiplicity. The verifier may deduplicate the AND while retaining these multiplicities in the analysis. An irreducible binary modulus of degree log₂ Q can be found by enumerating monic candidates and testing divisibility by monic polynomials through half the degree, in time polynomial in Q. There are at most Q² calls. Generating this schedule costs polynomial time in k and 1/λ_i. [Alon–Goldreich–Håstad–Peralta, §5, Construction 3 and Proposition 3](https://www.math.tau.ac.il/~nogaa/PDFS/aghp4.pdf)

Use normalized uniform inner products and let T_i f(x) average f(x+h) over mask occurrences. Each binary sign character is an eigenfunction, so T_i on zero-mean functions has operator norm at most λ_i. If a set J of density j has no shifted edge to E_i, the inner product of its indicator with T_i applied to the failure indicator is zero. Center both indicators and apply Cauchy–Schwarz. Squaring gives

    j p_i ≤ λ_i² (1−j)(1−p_i).

For j > 0 this yields p_i ≤ λ_i²(1−j)/(j+λ_i²(1−j)). Empty J is immediate separately. Both sets can depend arbitrarily on every physical proof value. BV14 already uses this Cayley-graph sampler, states the bound j ≤ λ_i²/p_i, and applies it to the *entire* NO verifier by repeating the full test. The factor 1−j in the centered estimate matters when few translated centers fail. [Ben-Sasson–Viola, §§4.3–4.4, Lemmas 4.7–4.8](https://eccc.weizmann.ac.il/report/2014/017/download/)

## Count roots of the once-evaluated residual

Suppose at a NO instance every allowed tuple of low-degree polynomials has a nonzero residual with at most bN roots, for a known 0 ≤ b < 1. The two-root analysis in Expedition 038 gives b = 1/4 as an upper bound. Let t_i count the residual's reads of physical word i, each at x+d for fixed d, including d = 0. Let J consist of seeds passing both the translated proximity checks and the single physical residual. All shifted calls on J pass, so centered mixing applies to each i with the same j.

Fix one nearest polynomial P_i for each entire physical word before considering individual reads. Every read map is a permutation, so its pulled-back mismatch density equals δ_i even when x+d itself fails as a check center. Outside the union of these mismatch sets, the physical residual equals the polynomial residual using the fixed tuple. Therefore

    j ≤ b + Σ_i t_i δ_i.
    A = Σ_i t_i C_i λ_i².
    j (j−b) ≤ A (1−j).
    j ≤ (b−A + sqrt((b−A)² + 4A))/2.

The first inequality holds even if reads coincide. The second inequality in j uses p_i ≤ λ_i²(1−j)/j for j > 0. Its j = 0 case holds directly. For 0 < η < 1−b, choose A ≤ η(b+η)/(1−b−η); evaluating the quadratic at b+η gives j ≤ b+η. For b = 1/4 and η = 1/8 it suffices that A ≤ 3/40. Field rejection is then at least **5/8**. Choosing the same λ² at most (3/40)/(Σ_i t_i C_i) for both roots meets this budget. Inverse-polynomial η, fixed rates and polynomially many translated reads still cost polynomial time in k. For rate exponent a ≥ 3, use K_a = 2^a+387 and C_i = (2 K_a)^h, where h = 0 for k ≤ 2a and h = 1+floor(log₂(k−2a)) otherwise. These are the constants in the Expedition 038 derivation with c₀ = 128 from the proof of the bivariate agreement lemma, so the schedule can be chosen uniformly. [Ben-Sasson–Sudan, §6.6, proof of Lemma 6.13, p. 595](https://people.csail.mit.edu/madhu/papers/2005/rspcpp-full.pdf)

This compares one unchanged residual against its legal-polynomial root cap. Repeating the whole joint verifier as in BV14 asks different residual questions and can yield much smaller acceptance. Here a single polynomial per word accounts for the translated read errors, without supposing its addresses are themselves accepted centers. The cap plus slack is an upper bound. Its attainment remains a separate question. Honest extensions pass every translated proximity test.

Each fixed translated raw query remains a signed projection with the same fiber count. The public field computations may depend on the seed, using the established seed-pin construction. If the compiled circuit has M_new clauses, the field rejection lower bound yields at least (1−b−η)/M_new rejection for **one uniformly sampled physical clause** by the Expedition 038 gate-output and pin argument. For a fixed field-proof assignment with actual field rejection r, the minimum over the auxiliary gate and pin tables is exactly r/M_new in this single-output construction. The same pin and gate lower bound applies at that fixed assignment. For equality, store every actual seed bit and every computed gate truthfully on all seeds. Exactly the output-true clause fails on each rejected seed. Numerical determination of the minimum over the field proof itself remains separate. Extra copies may increase the denominator and the encoded proof width. The sufficient bit approximation inequality uses the actual new width m and clause count, namely 3·2^(m−k+1)·η_bit < (1−b−η)/M_new. An improved symbol bound alone does not imply a looser single-clause precision requirement. [Expedition 038 compiler](../038-recursive-query-fibers/source-compiler.md)

## Exact finite controls

Run `python check_mixing.py`. It computes all nontrivial Fourier coefficients from the mask multiplicities and checks centered mixing for every base-failure subset at cube dimensions three and four. A separate toy arithmetic control uses words on GF(8), strict degree cutoff one, fixed read offset d = 2 and residual X+A(X+d). For a constant A the residual has exactly one root. The program enumerates words planted to make this residual vanish on selected sites, paired with every abstract failure set satisfying δ ≤ 2p. These failure sets test the inference from its scalar hypothesis; their realization by recursive RS leaves is not assumed.

For one such pair, the original failure set is {0}. The translated test accepts at {2,4}. The physical word has A(0) = 2, A(6) = 4 and zeros elsewhere. Both centers satisfy the physical residual. Neither read address 0 nor 6 is an accepted center, and a constant-polynomial residual can accept on only one site. The joint bound applies with one word. This control rules out treating the accepted centers as closed under every outer read shift or dropping the mismatch term from this abstraction. [Expected JSON](mixing-checks.json)
