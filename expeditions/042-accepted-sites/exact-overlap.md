# Exact physical overlap from the shape of the recursion

Use the RS read sets from the offset-indexed, all-fresh-tapes schedule of Expedition 038 at fixed rate exponent $a$. Write $W_z$ for the set of canonical physical symbol addresses read by one test at seed $z$. It contains the external root cell at $z$: the all-row path with fresh words zero and the inherited leaf point returns to it through every parent. A seed translation acts on physical addresses by shifting each saved high label at a row edge, passing the low shift padded with zeros to the child. At a column edge it shifts the saved low label with zero padding and passes the high shift to the child. A parent-return guard on fresh positions is unchanged. At a column-to-sibling redirect the sibling label gains the high shift and its local point gains the low shift, with the marker unchanged. This is exactly the change for a genuine row child. Thus $W_z=\tau_z W_0$. Two views $W_c,W_z$ intersect precisely when $z+c$ belongs to the base overlap set $K$. This concerns addresses; translating a fixed proof's verdict need not preserve it.

## Possible displacements

Build the binary tree of down shapes, ignoring labels and fresh values. Start with the ordered vector of $k$ original bit tokens. A row child takes the low tuple followed by $a$ fresh placeholders. A column child takes the high tuple. A leaf $i$ retains a set $B_i$ of original positions. Every split sends each live original bit to exactly one child, so the nonempty leaf blocks partition the original positions. A leaf can have zero original bits. Each block has size at most $2a$. Let $E_i$ be the binary coordinate subspace on $B_i$. For an internal node $w$, let $r(w),c(w)$ be the leaves reached by choosing its row or column edge respectively and thereafter choosing only rows.

For any physical address, trace its canonical owner shape downward with tokens. The saved edge labels and terminal point jointly contain $k$ positions belonging to the original tokens. A raw read at seed $z$ with down leaf $i$ fills those positions with $z+e$ for some $e\in E_i$. Only the leaf offset flips original bits, and then only the original tokens retained at that leaf. Row returns reverse the split and drop fresh positions. The column-to-row redirect exchanges the high and low tuple roles exactly as in the row sibling, so the token position associated with a canonical cell does not depend on which route reached it. A rectangle marker or fresh pad never occupies an original-token position.

A physical root cell is reached only from the all-row down path. A nonroot cell has an owner shape ending in a row, say $wR$. A route to it enters either $wR$ and stops on returning to that row, or $wC$ and redirects to its row sibling. All deeper edges must be rows, since a deeper column return would stop at its own sibling. Thus two distinct down shapes reaching the same cell must end at $r(w),c(w)$ for some internal node $w$. Comparing their common cell's original-token positions bounds $K$ by the union of all single $E_i$ and all $E_{r(w)}+E_{c(w)}$.

## Realizing the union

At a fixed leaf shape any change supported on its surviving original tokens leaves every saved edge label unchanged. Full-leaf enumeration may still select the old absolute coordinate by changing the offset. Thus every cell reached by this leaf can still be read, proving that every single $E_i$ belongs to the overlap set.

For each $w$, follow its fixed prefix at seed zero with all prefix fresh bits zero. Take its row branch with fresh word zero except for the rectangle marker one. Descend the all-row tail using fresh words zero and the inherited leaf point. Every deeper edge returns and the ascent stops on the common rectangle site of row label zero. Alternatively take the column branch at $w$ with fresh bits zero, and descend its all-row tail with fresh words zero, returning its inherited zero coordinate to the column. The sibling redirect reaches the same row label zero with zero low bits, zero auxiliary bits and marker one. Both routes stop here. Their prefixes agree even if they contain earlier column edges. Changing either seed on its own leaf block still allows the same physical address. Applying the seed-translation action to the pair gives every element of $E_{r(w)}+E_{c(w)}$ as an overlap with seed zero. This establishes the reverse inclusion.

The two leaves in each internal-node pair have that node as their unique lowest common ancestor. Thus two distinct nonempty blocks can make a two-block contribution together at most once. Count masks that are nonzero on one block separately from those nonzero on both. With $u_i=2^{|B_i|}-1$, the exact count including zero is
$$
|K|=1+\sum_i u_i+\sum_{w\text{ internal}}u_{r(w)}u_{c(w)}.
$$
Zero-token leaves contribute zero even if there are many of them. There are at most $2^h$ leaves and $2^h-1$ internal nodes, where $h=1+\lfloor\log_2(k-2a)\rfloor$ for $k>2a$. It follows that $|K|=O_a(k)$. Every original coordinate appears in one block, so all k unit displacements and zero belong to K, giving the matching lower order.

For a mask set $H$ containing zero, the augmented view equals the union of the $W_{z+h}$ over $h\in H$. Its overlap set is exactly $K+H+H$. For a subgroup of size $t$, this becomes $K+H$ and has size at most $t|K|$. For an arbitrary set the bound is $|H+H|\,|K|$. If zero is absent and the external center is added separately, enlarging $H$ by zero gives an upper bound. This counts physical symbol incidences without assuming that field verdicts are invariant or that calls are independent.

The planting construction may replace $q^2$ by this overlap size, without changing the raw query budget. At fixed rate the excess joint acceptance of the designed NO witness can be at least order $1/(tk)$ for polynomial-size subgroup schedules at sufficiently large $k$. Exact accepted-site agreement would require $|K+H|\ge N-D+1$ and hence $t=\Omega_a(N/k)$ in the subgroup case. This necessary condition gives no converse decoding theorem.
