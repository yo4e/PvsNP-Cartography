# One input per length

Viola's §2.3 argument fixes a language input x after obtaining a pointwise approximation. For arbitrary binary inputs, a joint uniform error guarantee on (x,y) can be entirely concentrated at one x. The tally-language executions in BV14 §3 and Viola §5 suggest a different encoding for a new comparison. [BV14](https://eccc.weizmann.ac.il/report/2014/017/download/) · [Viola, revision 5](https://eccc.weizmann.ac.il/report/2020/015/revision/5/download/)

For input 1^n there is exactly one relevant instance at each length. Let m₀(n) be the bit-proof address width of the specified compiler, with m₀(n)≤n+O(log(n+2)). Choose a fixed computable, strictly increasing M(n)=n+C ceil(log₂(n+2))+C dominating m₀, including small n. Decode n from the supplied bit length by binary search. For each n, put the original proof addresses in a subcube with M(n)−m₀(n) fixed zero bits. The extended verifier reads only this subcube. Fill the other cells with zero. Completeness and no-instance soundness on one global proof are preserved by restriction or extension.

Let g(y) at length M(n) be the addressed bit of the lexicographically first satisfying proof of this instance, or zero when no satisfying proof exists. At lengths outside the range use zero. This defines one language: a deterministic exponential-time machine can build the conjunction of the verifier clauses for all seeds (exponential size), use a SAT oracle to check whether a satisfying extension of a prefix exists, and determine the desired proof bit by prefix search. The number of calls and each query length are at most exponential in M(n); their product is still exponential. This establishes the indicated E^NP resource upper bound given a uniform compiler. No advice string selecting a hard x is needed.

A uniform average approximation to g **at that length** is already measured on the desired address cube. Padding changes the density multiplier from 2^(m₀−k+1) to 2^(M−k+1); the cost is polynomial but must be counted. The relevant premise is approximation on all sufficiently large required YES lengths to derive the corresponding simulation; occurrence on an arbitrary infinite set might miss them. Unused lengths where g is zero cannot witness hardness. A degree-preserving majority of a point mass does not convert constant average error into the small inverse-polynomial error in the compiler estimate. The unary observation removes a conditioning loss and leaves that precision and the final running-time comparison to [Issue 29](https://github.com/yo4e/PvsNP-Cartography/issues/29). This note does not claim a new hierarchy consequence.
