# Replay, fiber bound and attacks on the RS-PCPP coordinate model

The source is Ben-Sasson and Viola, ECCC TR14-017, Definition 6.2, Proposition 6.1 and §§6.2–6.3, pp. 18–21. The convention below uses parent membership in Eq. (9) with the row basis of Definition 6.2. In this convention the auxiliary row coefficients, including the final marker, all vanish at a parent redirect. Proposition 6.1 puts the entire column in the complement of the parent set. [Primary report](https://eccc.weizmann.ac.il/report/2014/017/download/)

**Exact conditional fiber.** Fix a down path, all fresh auxiliary bits, one absolute leaf coordinate, and any fixed seed translation. Keep the full canonical address, consisting of the surviving path with all edge labels and the terminal coordinate. Let the root contain `k` different data symbols. Before setting the leaf coordinate, down-splitting and appending fresh symbols distributes those `k` symbols without repetition among the edge labels and the leaf tuple. Let `u` be the number in the leaf tuple. Replacing that tuple by the chosen absolute point erases exactly `u ≤ k_leaf ≤ 2a` root symbols.

On each continuing return, the current tuple is the same ordered tuple supplied on descent with some positions replaced by leaf constants. This holds at the leaf. For a row, the saved label is `H` and the incoming child tuple was `L || E`, where `E` was fresh. The row membership test reads only `E` positions. Each now contains its original fresh value or a leaf constant. The return decision is therefore independent of the root data. Stopping retains `(H, L′ || E′)`. Returning to the parent removes `E′` and gives `L′ || H` in original order. It can remove no surviving root symbol. For a column, the saved label is `(L,t)` and the current coordinate is `H′`. Redirection names the row `H′`, with coordinate `(L,t,1)`, and terminates there. These are the same column and row point by Definition 6.2 and Proposition 6.1. The label swap discards no surviving root symbol. Untraversed ancestor labels remain part of the address.

Consequently each terminal payload contains exactly one copy of every original root symbol outside the erased `u` positions. All other bits in the fixed layout are constants. An inverse reads the surviving symbols in their original positions and inserts arbitrary bits into the erased positions. The root-to-address projection has rank exactly `k−u`, every nonempty fiber contains exactly `2^u` roots, and each attained address has probability `2^(u−k)` under a uniform root. For fixed XOR seed translations the inverse also removes the known XOR. The bound `u ≤ 2a` is sharp in this model. Take `k=2^d · 2a` and always descend a column. Its child tuple consists only of the high root bits and ends with precisely `2a` of them. An absolute leaf query erases all those bits.

**Leaf-index convention.** BV14 p.20 also describes flipping leaf-coordinate bits. One may index the full set of leaf queries by fixed XOR offsets from the inherited leaf point. Then no data symbol is overwritten: replay uses the original symbols with known flips. Each row suffix tested on the way up consists of original fresh bits, perhaps flipped, so the return decisions are still independent of the root. The root rank is exactly `k` in this fixed-offset model. Absolute indices and offsets visit the same entire leaf domain for each seed. A generic ordered decision cannot identify those lists: on the leaf truth table `(0,1)`, deciding by the first answer returns zero in absolute order and one when the inherited leaf point is 1 and the offsets are ordered `0,1`. An arbitrary ordered predicate must receive answers reindexed by the public permutation `i ↦ i XOR v`, where `v` is the inherited leaf coordinate. Account for the reindexing in any succinct bit-level construction.

For the specific exact leaf RS-membership predicate described on p.17, there is also a predicate-level invariance. Write the leaf domain as `b + Span(B)` and let `s` be the linear combination of `B` with coefficients `v`. Reindexing by XOR sends the field point `x` to `x+s` within that same affine domain. The existence of a univariate polynomial `P` of degree less than the threshold representing the table is equivalent for the translated table: `P(X+s)` has the same degree, and translating a second time is the inverse. This argument is for all received tables, including failing ones. It does not assert invariance of later predicates on selected bits, arbitrary postprocessing, or the weights assigned to clauses in a Cook–Levin presentation.

**Common cube and probabilities.** For maximum depth `D`, use two bits per level (row, column, unused). Pad the shape with unused markers, concatenate all edge labels and the final coordinate, and right-pad that payload to `k+aD`. The dimensions and field widths follow from the shape. Every row descent increases total labels-plus-coordinate length by `a`, every column descent by `a−1`; this holds for the terminal path including a redirected row. Fixed shape and width make the encoding injective and 1-local on each fixed transcript. Its width is `m = k+(a+2)D`. Hence density relative to the full cube for this word-address encoding is at most `2^(m−k+u)`, polynomial in `k` when `a` is fixed and `D=O(log k)`. Unused bit strings stay in the uniform-address denominator. The output describes one word, before incorporating proof-block names and field-bit indices.

For a root-independent distribution on the frozen auxiliary strings the unconditional point mass is a weighted average of the conditional masses and is at most `max 2^(u−k)`. For independently selected normalized query types `j`, the density bound is the weighted sum of their bounds. A verifier that reads a whole list and requires every test to pass must sum occurrence bounds or use its actual test weights; correlation among answers does not justify discarding the list length. For any root-dependent choice from `J` fixed queries, a union bound gives `Pr[output=y] ≤ sum_j 2^(u_j−k)` when each fixed query has the indicated unconditional point bound. Extra simulated pad bits can produce many seed preimages even when probabilities satisfy this bound; counting all `k+e` seed bits instead of root bits alone multiplies the loose fiber upper bound by `2^e`.

**Stress tests.**

* Remove path labels and choose a row leaf with absolute point outside the parent set. The local coordinate is constant for every root, while the original labels keep the surviving seed bits. Reconstruction fails without the labels.
* Overwrite `h` surviving input positions with constants (for example, force the leading bits of an identity address to zero). Each distinct lost bit can double a fiber. For a fixed absolute-overwrite mask `M` on the root in the above model the exact exponent is `|M ∪ U|`, where `U` are the root positions occupying the leaf. Forcing genuine fresh extension bits does not incur this root-bit cost. Conditioning on `h` root bits changes the distribution to a subcube; it does not preserve the original root measure.
* An adaptive selector can attain the list-length penalty. For every `s` in an `h`-dimensional coordinate subspace use the full-rank map `x ↦ x+s`. Choosing `s` equal to the first `h` bits of `x` zeros those bits of the selected address. Each individual map has density one; their selected output has density `2^h`. A fixed shift or a root-independent mixture behaves differently.
* Mapping several canonical locations onto one unvalidated physical alias can add their masses. Even the identity map loses `h` bits if its first `h` output positions are cleared. Conversely an injective but nonlinear relabeling preserves fiber cardinalities while potentially destroying projection degree. Both properties need checking for the actual combined proof encoding.
* No amount of word-address smoothness alone removes the separate language-input hardwiring cost: the constant approximant zero against `f(x,y)=[x=0]` has mean error `2^{−|x|}` and error one on the designated slice. A fixed-input error guarantee or another transfer is required for that step.

This argument covers the explicitly encoded internal coefficient model. It does not instantiate all blocks, actual outer test weights, Boolean proof bit addresses, auxiliary Cook–Levin queries, or the fixed-input approximation promise. Neither the rank nor the density here is a certificate for that combined system.
