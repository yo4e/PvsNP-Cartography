# Barrier and scope audit

This expedition proves no complexity-class relation. Its proposed structural
lemmas are elementary encoding, interpolation, decoding and counting
arguments; the executed results are finite controls. None is a barrier escape.

## Relativization

No P/NP oracle separation is attempted. The shared-map decoder is a finite
identity and the dimension obstruction concerns a specified finite code
family. A future hierarchy application would still need its explicit uniform
source compiler and approximation premise; no nonrelativizing step is supplied
here. BGS remains a constraint, not a discharged condition.

## Natural Proofs

The code covering calculation counts low-degree Boolean polynomial
restrictions. It does not establish a constructive, large property useful
against general circuits. In particular a hard satisfying witness in a
code-only relaxation is not a hard language, and it need not be the witness
chosen in an existential completeness argument. No unconditional general
circuit lower bound or cryptographic consequence is inferred.

## Algebrization

Reed–Solomon interpolation and symbolic linear evaluation are algebraic
mechanisms. Their use supplies no demonstrated failure of the asymmetric
algebraic-oracle framework. A proposed source-level lower-bound extension
would need a separate audit. Disposition for barrier escape: unknown / not
established.

## Concrete boundaries

- Original growing YES fixture: unique used proof; no incompatible pair.
- Public dictionary: requires a public algorithm for coefficient vectors,
  a proved seed-degree bound, and a small enough dictionary. Storage and public
  preprocessing time are separate costs.
- RS obstruction: for every fixed layout, some satisfying code-only witness
  fails. It does not say every witness fails or preserve the original NO gap.
- Guessed layout: one row map must be shared by every occurrence. Collision
  alone does not destroy NO soundness, but changes the error metric/sensitivity.
- Full explicit row-map guessing costs R*t bits. In the growing one-level
  family this already exceeds the intended o(N) decision time.
- The new twelve-row relation is easy; its NO minimum is four and its strict
  raw error allowance is below one. It is a positive encoding control, not an
  improved error-radius construction or a hard instance family.
