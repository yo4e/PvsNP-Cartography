# Accepted-site attacks

- **Sparse interpolation.** The one-center physical witness passes on 120 zeros and one one, at strict degree cutoff 32. In the general argument the dense accepted zero set alone has at least D points. The root being close to zero does not repair exact agreement.
- **Sharing and quantifiers.** Use one value for each canonical address. Patch all center views from the *same* second honest proof even if they overlap. Require disjointness only for the exterior sites retained from the first proof. The added root site accounts for the outer evaluator's actual read.
- **Incomplete accounting.** The large-field counterexample fixes A to the honest zero word. Testing an arbitrary affine A by scanning every root point would exceed the asymptotic query budget. For this witness one can fix it publicly or use a separate perfectly complete polynomial-cost test.
- **Loss of translation invariance.** Passing RS at a center does not imply passing at each address of the outer residual. The joint bound pulls back global mismatch sets via the actual permutations. Finite controls realize a case in which all relevant read addresses lie outside the RS passing set. Use weighted biases even when the AND is evaluated on distinct masks.
- **Low-depth gluing.** An outer common column of parity p has inner parent index bit a equal to p in every row. Gluing checks only this class, then joins a second class if both passed. Few rows need direct interpolation in Y. At a=3 the 2/3 lower bound holds, but that single rate has no tightness witness from the earlier Frobenius estimate.
- **Denominators.** An existential codeword explaining nearly every accepted site can depend on the shared assignment. Its existence supplies no efficient decoder. Field-seed rejection, physical clause rejection and the probability that a read address mismatches have different sample spaces. The larger Boolean verifier may dilute the field gain. Human review, Lean checking and novelty remain open for these derivations.
