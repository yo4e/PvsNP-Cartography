# Attack record: useful precision after actual Boolean compilation

The lead and separate mathematical, compiler and weighted-countermodel agents
checked different parts, then inspected one another's code and proofs.

1. **A small singleton count is not an upper bound.** The old singleton gives
   only `sigma>=288`. The missing upper bound was supplied by a complete
   true-address assignment with maximum 288 and total mass 10,706,688. Every
   greedy choice is checked at its actual signed physical literal. The new
   all-error gate inequalities include mixed errors, not just singletons.
2. **Physical aliases can multiply an input's cost.** Mandatory buffers use
   canonical maps, not down-path names. The old input `(tag,delta)` pairs are
   preserved exactly. Independent query routers verify small full seed views.
   Removing one input buffer creates a 250-failure singleton.
3. **Private gates and pins can dominate.** Fanout counts occurrences, signs,
   and the final assertion. AND output error costs two, not one; clamped pins
   cost two globally. Omitting a private split creates a 199-failure singleton.
4. **A copy tree might destroy soundness.** Every copy belongs to one center.
   A wrong constant already violates its unit. With correct constants/pins,
   all satisfied equivalences force the original verdict. Bad pins are charged
   with their exact multiplicity. Thus every field rejection costs at least
   one pair, and honest gate evaluation attains the field minimum 109.
5. **Storage might cancel the improvement.** It does cancel half the cap-two
   gain. Cap 126 fits both YES and NO within the original power-of-two cube.
   The actual census is used, not an unpadded row comparison.
6. **Different clause denominators might be mixed.** All displayed thresholds
   use raw failed-pair counts, with common NO threshold 109 for this fixture.
   YES and NO normalized rejection fractions have different denominators.
   A family-wide claim needs its own uniform bounds and common convention.
7. **Weighting might repair shared amplification for free.** Symmetric copy
   weight t repairs the numerator and raises sensitivity to 2t. Arbitrary
   private-clause weights retain the half-bound. Dropping copy symmetry is
   false; a positive-weight counterexample is preserved, and its proper
   asymmetric unshifted baseline is explicitly compared.
8. **Finite execution might be promoted to a broader result.** The 142 field
   fixtures are bounded conformance controls. The general map/copy arguments
   are written separately. The old exact 288 is for the named honest proof;
   a changed encoded truth function needs its own approximation hypothesis.
   Unrestricted singleton extremizers need not obey a fixed low degree.
9. **A larger numerical budget might leave the same existential hypothesis.**
   Both thresholds are below 1/Q. The deterministic certified radius stays
   zero; any qualifying mixture must contain an exact polynomial with positive
   probability. Thus the ratio change does not establish a larger class of
   approximable truth functions. A one-symbol A error makes the retained field
   predicate reject everywhere, forcing sigma>=N; truthful NO auxiliaries give
   V_NO<=N. This stronger obstruction changes Issue 34's target to crossing
   V_NO/sigma=1 with a changed test/representation or a justified error model.

No attack found a defect in the repaired claims within their stated models.
